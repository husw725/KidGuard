# 题目优化模式总结

## 1. 去重策略
- **文本摘要**: 使用 question 字段的 hash 值或标准化的纯文本字符串作为唯一键。
- **差异分析**: 若题目相同但选项不同，应合并为更优的选项集。

## 2. 正确选项定位逻辑
- 约定 `answer` 字段存储正确答案的索引或文本值。
- 在数据加载时应验证 `answer` 是否存在于 `options` 数组中。

## 3. 奥数题模板
- 模板格式: `{"question": "...", "options": [...], "answer": "..."}`
- 逻辑约束: 奥数题必须包含解题步骤说明，可扩展 `explanation` 字段以提升用户体验。
