# 小欣学习 (KidGuard) 🚀

一款专为家长设计的 Android 强制学习锁机应用。通过不可绕过的全屏锁屏，强制孩子在玩手机前完成 **语文 / 数学 / 英语** 练习，实现“以学代练，碎片化提升”。当前面向**人教版二年级（升三年级）**孩子定制。

## 🌟 核心功能

*   **强制锁屏答题**：全屏悬浮窗拦截，不答对指定数量题目无法进入系统。
*   **三科覆盖 + 自适应难度**：语文 / 数学 / 英语混合出题；难度分三档，**连续答对升档、答错降档**，题目难易随孩子水平动态调整。
*   **动态数学引擎**：实时生成口算、应用题、奥数思维题，以及**巧算/简便计算**题（如 `198+66→200+66-2`、`85-33+15→85+15-33`，重在教方法）。
*   **英语启蒙（听音选图）**：内置真人发音音频 + emoji 图片选项，**零基础也能玩**——听单词、点图片，对标人教版三年级起点。
*   **防死记设计**：阅读理解、应用题等**参数化随机生成**，姓名/数量/颜色等每次都变，答案随之变化，杜绝背答案。
*   **趣味化**：谜语、脑筋急转弯、随机鼓励语，主角用“小欣”，激发学习兴趣。
*   **艾宾浩斯记忆法**：错题自动记录，按“多久没出现 + 错过几次”加权重现，直到孩子彻底掌握。
*   **云端题库同步**：支持通过 Gitee 代码片段（JSON）远程下发语数题目，实现热更新。
*   **音频焦点劫持**：锁屏时强行暂停系统声音（小说、视频、音乐等），确保专心答题。
*   **家长实时战报**：每次答题结果（得分、正确率、错题本及标准答案）自动推送到家长钉钉机器人。
*   **极致防绕过**：集成了设备管理器、无障碍服务、前台服务以及断点续答机制。

## 📚 题目体系

*   **数学**：课内口算 → 应用题（植树、排队、年龄、和倍、单位换算…）→ 奥数思维（鸡兔同笼、数列规律、倒推还原…）→ 巧算简便（凑整法、加减搬家凑整）。
*   **语文**：字形部首、拼音多音字、近反义词、量词、成语歇后语、古诗名言、仿写/标点/句子排序、**参数化阅读理解**、谜语。
*   **英语（启蒙）**：以**听音选图**为主（动物/颜色/数字/水果/食物/天气），辅以中英互译、字母大小写与顺序、情景对话；每次答题少量穿插。
*   **干扰项**：均贴合孩子常见错误（如凑整忘调整、加减误当成减去和、近义词混反义词），错一次即点中误区。

## 📱 手机端必要设置说明 (必读)

为了确保应用能够稳定运行且不被“熊孩子”关闭或卸载，请务必在安装后完成以下设置：

### 1. 核心权限授权 (应用启动时会引导)
*   **显示在其他应用上层 (悬浮窗)**：用于展示锁屏界面。
*   **激活设备管理器**：防止应用被直接卸载。激活后，需先在设置中取消激活才能卸载。
*   **开启无障碍服务 (Accessibility)**：**【最重要】** 用于对抗系统的“一键清理”强杀。开启后，系统杀掉进程会立刻被无障碍服务拉起。

### 2. 系统保活设置 (不同机型略有差异)
*   **允许自启动**：在手机管家或设置中，将“小欣学习”设为允许开机自启和后台关联启动。
*   **关闭电池优化**：在电池设置中，将本应用设为“不优化”或“允许高耗电行为”，防止系统因省电杀掉后台。
*   **多任务加锁**：打开手机多任务界面（最近任务），下拉“小欣学习”卡片并点击“小锁”图标，防止一键清理。

## 🛠️ 家长远程维护指南

### 题库更新格式
请在 Gitee 创建代码片段，使用以下 JSON 格式维护：

```json
{
  "version": 1, // 每次修改题目后请将此数字加1
  "questions": [
    {
      "text": "题目内容",
      "options": ["选项A", "选项B", "选项C", "选项D"],
      "correctIndex": 0 // 正确答案索引，0代表第一个选项
    }
  ]
}
```

### 钉钉配置
当前版本已硬编码钉钉 Webhook。如需更改，请修改 `FloatingService.kt` 中的 `CLOUD_URL` 及其上方的 Token。

## 🏗️ 技术架构
*   **语言**：Kotlin
*   **平台**：Android (Min SDK 24)
*   **核心类**：
    *   `FloatingService`：管理锁屏 UI、答题逻辑、音频劫持、英语题发音（MediaPlayer 播放预置音频）与钉钉汇报。
    *   `QuestionBank`：题目调度与加权选题（防重复 + 错题加权）、难度自适应引擎、参数化语文/阅读题、云端同步。
    *   `ThinkingMathGenerator`：奥数思维题（植树、锯木、年龄、和倍、鸡兔同笼、数列、倒推…）。
    *   `OlympiadMathGenerator`：奥数题（周期律、数列规律、简单代数推理）。
    *   `SmartCalcGenerator`：巧算/简便计算题（凑整法、加减搬家凑整）。
    *   `EnglishGenerator`：英语启蒙题（听音选图为主）。
    *   `Datas.kt` / `ThinkingChineseQuestions`：语文静态题库。
    *   `LockAccessibilityService`：确保进程被杀后秒级复活。
*   **资源**：`app/src/main/res/raw/` 预置英文单词发音音频（.m4a，约 48 个），英语题发音不依赖手机 TTS 引擎。
